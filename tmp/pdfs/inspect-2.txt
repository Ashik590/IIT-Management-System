9. Data Flow Diagram (DFD)
A data-flow diagram is a visual representation of how data moves through a system or a process.
A data flow diagram (DFD) shows how information moves through any system or process. It
displays data inputs, outputs, storage locations, and routes between each destination using
predefined symbols such as rectangles, circles, and arrows as well as brief text labels.
